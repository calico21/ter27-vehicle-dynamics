# CasADi Solver Cache (`outputs/casadi_cache/`)

This directory stores compiled CasADi shared libraries (`.so`), generated C sources (`.c`), and NLP warm-start artifacts used by the TeR27 optimal control and lap-time simulation solvers (`vd_correlation_lab/oracle/`).

Generated cache files are ignored by `.gitignore`; only this `README.md` and `.gitkeep` are tracked in Git.
